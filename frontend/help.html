PMAS Help

PMAS shows how project hours and costs compare with the plan. You import timesheet files, and PMAS calculates the results.

Quick start

  1. Open the Cycles tab. Create a cycle. A cycle is a billing period.
  2. Open the Projects tab. Register a project with a PEP code and a budget.
  3. Open My Area, then Upload. Import a timesheet file.
  4. Open the Dashboard tab. Select a cycle or a PEP. Click Load.

The tabs

Dashboard
Charts for team effort, portfolio health, and forecast.
Projects
The list of projects, with budgets and baselines.
Cycles
The list of billing periods.
Team
Seniority levels, rate cards, and the team list.
My Area
Your preferences, your imports, and your alerts.
Admin
Only an administrator sees this tab. It has users, rules, quarantine, and the audit log.

The import file

The file must be a CSV or an XLSX file. The maximum size is 20 MB. Keep the column names exactly as shown below.

ColumnRequiredMeaning
ColaboradorYesName of the collaborator
DataYesDate of the work
Horas totais (decimal)YesTotal hours for the day, in decimal format
Hora extraNoOvertime hours
Hora sobreavisoNoStandby hours
Código PEPNoThe PEP code of the project
PEPNoThe description of the PEP

Do not edit imported data in PMAS. To correct an error, correct the source file and import it again.

Quarantine

A row goes to quarantine when it fails a validation rule. For example, a row with more than 24 hours in one day goes to quarantine. The system does not count a quarantined row. An administrator approves or rejects the row.

Terms

Cycle
A billing period with a start date and an end date.
PEP
The code that identifies a project.
Baseline
An approved budget. The system locks it, so nobody can change it. PMAS uses the active baseline as the budget.
CPI
The earned value divided by the actual cost. A value below 1 means that the project costs more than planned.
SPI
The progress against the schedule. PMAS uses hours as the base. A value below 1 means that the project is late.
EAC
The estimated total cost when the project ends.

Ajuda do PMAS

O PMAS mostra como as horas e os custos dos projetos se comparam com o plano. Você importa arquivos de timesheet e o PMAS calcula os resultados.

Início rápido

  1. Abra a aba Ciclos. Crie um ciclo. Um ciclo é um período de faturamento.
  2. Abra a aba Projetos. Cadastre um projeto com um código PEP e um orçamento.
  3. Abra Minha Área e depois Upload. Importe um arquivo de timesheet.
  4. Abra a aba Dashboard. Selecione um ciclo ou um PEP. Clique em Carregar.

As abas

Dashboard
Gráficos de esforço da equipe, saúde do portfólio e previsão.
Projetos
A lista de projetos, com orçamentos e baselines.
Ciclos
A lista de períodos de faturamento.
Equipe
Níveis de senioridade, tabelas de taxa e a lista da equipe.
Minha Área
Suas preferências, suas importações e seus alertas.
Admin
Somente um administrador vê esta aba. Ela tem usuários, regras, quarentena e o log de auditoria.

O arquivo de importação

O arquivo deve ser CSV ou XLSX. O tamanho máximo é 20 MB. Mantenha os nomes das colunas exatamente como mostrado abaixo.

ColunaObrigatóriaSignificado
ColaboradorSimNome do colaborador
DataSimData do trabalho
Horas totais (decimal)SimTotal de horas do dia, em formato decimal
Hora extraNãoHoras extras
Hora sobreavisoNãoHoras de sobreaviso
Código PEPNãoO código PEP do projeto
PEPNãoA descrição do PEP

Não edite dados importados no PMAS. Para corrigir um erro, corrija o arquivo de origem e importe-o de novo.

Quarentena

Uma linha vai para a quarentena quando falha em uma regra de validação. Por exemplo, uma linha com mais de 24 horas em um dia vai para a quarentena. O sistema não conta uma linha em quarentena. Um administrador aprova ou rejeita a linha.

Termos

Ciclo
Um período de faturamento com data de início e data de fim.
PEP
O código que identifica um projeto.
Baseline
Um orçamento aprovado. O sistema o trava, então ninguém pode alterá-lo. O PMAS usa a baseline ativa como orçamento.
CPI
O valor agregado dividido pelo custo real. Um valor abaixo de 1 significa que o projeto custa mais que o planejado.
SPI
O progresso em relação ao cronograma. O PMAS usa horas como base. Um valor abaixo de 1 significa que o projeto está atrasado.
EAC
O custo total estimado quando o projeto termina.
